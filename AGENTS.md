# Standard Work Repo

This repository packages Dru's reusable standard work for coding agents as an Agent Skills / Pi package.

When editing:

- Keep `skills/standard-work/SKILL.md` concise and focused on routing/lazy-loading instructions.
- Put detailed standards in `skills/standard-work/references/`.
- Update `skills/standard-work/references/index.md` for any added, removed, or renamed reference.
- Avoid duplicating large guidance in top-level files; the point is lazy loading.
